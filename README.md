# 🤖 AI Document Assistant - RAG Chatbot

## 📌 Overview

AI Document Assistant is a Retrieval Augmented Generation (RAG) chatbot that allows users to upload documents and ask questions about them.

The application uses document retrieval with Large Language Models to provide accurate answers based on the uploaded files.

---

## 🚀 Features

- 📄 Upload PDF documents
- 🔍 Extract information from documents
- ✂️ Split documents into smaller chunks
- 🧠 Generate embeddings using Gemini Embedding Model
- 🗂️ Store embeddings in Chroma Vector Database
- 🔎 Retrieve relevant information using similarity search
- 🤖 Generate answers using Gemini 2.5 Flash
- 💬 Chat-style interface using Streamlit
